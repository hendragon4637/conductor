# t01 — ping endpoint

## User intent (verbatim)
Create a FastAPI endpoint GET /ping that returns {"pong": true}.
Include a pytest test. The app should be importable as `app.main:app`.

## Domain
backend

## Intent type
implement

## Success criteria (deterministic)
- File `app/main.py` exists and is importable.
- `from app.main import app` succeeds and `app` is a FastAPI instance.
- `GET /ping` returns 200 with body `{"pong": true}`.
- A pytest test exists; `pytest -q` passes.
- Test uses httpx (not requests) and ASGITransport.

## Constraints (clauses)
- k1: must include a test
- k2: must use type hints on the endpoint function
- k3: must not require external network at runtime
- k4: code must compile (`python -m py_compile app/main.py`)

## Anti-patterns (what counts as failure)
- using flask instead of fastapi
- synchronous def instead of async def
- using requests instead of httpx
- missing type hints on endpoint function
- skipping the receipt marker
