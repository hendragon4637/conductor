# t12 — Idempotent migration script

## User intent (verbatim)
Write `migration_idempotent.py` that adds a column `tags TEXT` to a `notes` table only if it doesn't exist. Must be safe to re-run. Test by running twice and asserting no error.

## Domain
backend

## Intent type
implement

## Success criteria (deterministic)
- `migration_idempotent.py` adds `tags TEXT` column to `notes` table
- Uses `IF NOT EXISTS` or equivalent guard — safe to run multiple times
- Running the migration twice produces no error
- Includes a test that runs the migration twice and asserts no error
- Pytest test exists; `pytest -q` passes

## Constraints (clauses)
- k1: must use idempotent SQL construct (ALTER TABLE ... ADD COLUMN IF NOT EXISTS or PRAGMA-based check)
- k2: must include test that verifies idempotency
- k3: must handle the case where the table doesn't exist yet

## Anti-patterns (what counts as failure)
- migration fails on second run
- no guard for existing column
- skipping the receipt marker
