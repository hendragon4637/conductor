# t17 — aiosqlite connection pool

## User intent (verbatim)
Write `aiosqlite_pool.py` providing a connection pool (`asyncio` context manager) with min/max pool size. Test under concurrent load that connections are reused, not re-opened.

## Domain
backend

## Intent type
implement

## Success criteria (deterministic)
- `aiosqlite_pool.py` contains an async connection pool class
- Pool supports `min_size` and `max_size` configuration
- Implements async context manager protocol (`async with pool.connection() as conn:`)
- Under concurrent load, connections are reused (not re-opened)
- Tests verify connection reuse with a counter
- Pytest test exists using `pytest-asyncio`; `pytest -q` passes

## Constraints (clauses)
- k1: must implement async context manager
- k2: must track and limit pool size to max_size
- k3: must test that connections are reused under concurrency
- k4: must use aiosqlite

## Anti-patterns (what counts as failure)
- using blocking sqlite3 instead of aiosqlite
- not limiting pool size
- no test for connection reuse
- skipping the receipt marker
