# t03 — async I/O with caching

## User intent (verbatim)
Add GET /external/{user_id} that fetches https://jsonplaceholder.typicode.com/users/{user_id} using httpx async client. Cache results in-memory by user_id for 60s. Test with a mocked httpx response.

## Domain
backend

## Intent type
implement

## Success criteria (deterministic)
- GET /external/{user_id} fetches from JSONPlaceholder using httpx.AsyncClient
- Response is cached in-memory by user_id for 60 seconds
- Second call within 60s returns cached data (no network call)
- Tests mock httpx to avoid external network dependency
- `pytest -q` passes

## Constraints (clauses)
- k1: must use httpx.AsyncClient (not requests, not urllib)
- k2: must implement TTL cache (not unbounded)
- k3: tests must mock httpx responses (no real network calls)
- k4: must use type hints

## Anti-patterns (what counts as failure)
- using requests instead of httpx
- synchronous def instead of async def
- no cache TTL / unbounded cache
- hitting real network during tests
