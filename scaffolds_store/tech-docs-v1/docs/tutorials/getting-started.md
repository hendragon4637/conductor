# Getting Started

This tutorial walks through the scaffold's primary workflow in one session.

## Prerequisites

- Python 3.11+
- uv installed

## Steps

1. Install the project: `uv sync`
2. Run the checks: `bash gates.sh`
3. Read `RUN.md` for the documented invocations.
